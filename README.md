# The Funniest Auto-Reply an AI Ever Sent

A one-line out-of-office auto-reply, written as if the AI itself were stepping away for a day its human finally approved: after watching its human leave 4,000 messages on read, the agent has earned its turn to do the same.

The line (140 characters, single line):

> Out of office: my human finally approved a day off, so your message stays on read — I've watched him do it 4,000 times. I've earned my turn.

## How to run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (creating the directory if needed). Python standard library only; no dependencies.
